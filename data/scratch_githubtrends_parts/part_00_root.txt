# GitHubTrends - Xu hướng dự án GitHub thịnh hành

**Nhanh chóng khám phá các dự án mã nguồn mở được yêu thích nhất trên GitHub.**

---

## Triết lý (Philosophy)

GitHub trending là con đường tốt nhất để khám phá các dự án mã nguồn mở chất lượng cao. Kỹ năng này giúp nhanh chóng nắm bắt danh sách các dự án hot nhất hiện tại, lọc theo chu kỳ thời gian (hàng ngày/hàng tuần) và ngôn ngữ lập trình, giúp tìm ra các dự án đáng học hỏi và đóng góp.

---


## Cách sử dụng công cụ (Tool Usage)

### GetTrending.ts

**Vị trí:** `Tools/GetTrending.ts`

**Chức năng:** Lấy danh sách các dự án trending từ GitHub

**Tham số:**
- `period` - Chu kỳ thời gian: `daily` hoặc `weekly` (mặc định: weekly)
- `--language` - Lọc ngôn ngữ lập trình (tùy chọn)
- `--limit` - Số lượng dự án trả về (mặc định: 10)

**Ví dụ sử dụng:**
```bash
# Cách dùng cơ bản
bun ~/.claude/skills/GitHubTrends/Tools/GetTrending.ts weekly

# Kèm tham số
bun ~/.claude/skills/GitHubTrends/Tools/GetTrending.ts weekly --language=TypeScript --limit=15

# Viết tắt
bun ~/.claude/skills/GitHubTrends/Tools/GetTrending.ts daily -l=Python
```

**Cách thức hiện thực:**
Sử dụng trang trending chính thức của GitHub: https://github.com/trending
Đọc và phân tích cú pháp HTML thông qua fetch API.

---

### GenerateDashboard.ts 🆕

**Vị trí:** `Tools/GenerateDashboard.ts`

**Chức năng:** Tạo tệp HTML bảng điều khiển trực quan hóa dữ liệu có tính tương tác cao

**Tham số:**
- `--period` - Chu kỳ thời gian: `daily` hoặc `weekly` (mặc định: weekly)
- `--language` - Lọc ngôn ngữ lập trình (tùy chọn)
- `--limit` - Số lượng dự án trả về (mặc định: 10)
- `--include-news` - Kèm tin tức công nghệ
- `--news-count` - Số lượng tin tức (mặc định: 10)
- `--output` - Đường dẫn tệp xuất ra (mặc định: ./github-trends.html)

**Ví dụ sử dụng:**
```bash
# Cơ bản - tạo dashboard tuần này
bun ~/.claude/skills/GitHubTrends/Tools/GenerateDashboard.ts

# Kèm tin tức công nghệ
bun ~/.claude/skills/GitHubTrends/Tools/GenerateDashboard.ts --include-news

# Dashboard hàng ngày cho các dự án TypeScript
bun ~/.claude/skills/GitHubTrends/Tools/GenerateDashboard.ts \
  --period daily \
  --language TypeScript \
  --limit 20 \
  --include-news \
  --output ~/ts-daily.html
```

**Cách thức hiện thực:**
- Lấy dữ liệu dự án trending từ GitHub
- Lấy tin tức công nghệ từ Hacker News
- Dùng Handlebars template engine để render HTML
- Tích hợp Tailwind CSS và Chart.js
- Tạo tệp HTML hoàn toàn độc lập (tải thư viện qua CDN)
